WiFi Monitor

Tenda F6-এর স্থানীয় নেটওয়ার্ক তথ্য দেখার সহায়ক পেজ।

১. বাসার Wi‑Fi-তে যুক্ত হও

ফোনের Wi‑Fi থেকে নিজের Tenda F6 নেটওয়ার্কে কানেক্ট করো। মোবাইল ডাটা বন্ধ রাখলে ভুল নেটওয়ার্কে যাওয়ার সম্ভাবনা কমবে।

রাউটার প্যানেল খুলুন (192.168.0.1) বিকল্প ঠিকানা: tendawifi.com

রাউটারের নিচের লেবেলে দেওয়া Login IP-ও ব্যবহার করা যায়।

২. Tenda F6-এ কী দেখা যায়

  • ইন্টারনেট সংযোগের অবস্থা
  • কতটি ডিভাইস অনলাইনে আছে
  • রিয়েল-টাইম আপলোড ও ডাউনলোড গতি
  • অনলাইন ডিভাইসের নাম, IP ও MAC (ফার্মওয়্যার/পেজ অনুযায়ী)

এই তথ্যগুলো রাউটারের নিজস্ব Status / Bandwidth Control পেজে দেখা যায়।

৩. স্বয়ংক্রিয় মনিটরিংয়ের অবস্থা

এখনো রাউটারের সঙ্গে কোনো সরাসরি ডেটা সংযোগ করা হয়নি।

এই GitHub Pages পেজ একা রাউটারের ডিভাইস তালিকা বা ট্রাফিক ডেটা পড়তে পারে না। Tenda F6-এর নির্দিষ্ট হার্ডওয়্যার/ফার্মওয়্যারের API বা আলাদা Android স্থানীয়-নেটওয়ার্ক অ্যাপ লাগবে।

পরের ধাপের জন্য

রাউটারের প্যানেল খুলে Status পেজে যাও। নিচের তথ্যগুলো দেখে রাখো: Hardware Version, Firmware Version এবং Login IP। কোনো পাসওয়ার্ড বা Wi‑Fi key এখানে পাঠাবে না।
